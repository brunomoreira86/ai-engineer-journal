# Book Outline: "The AI Engineer's Journal" (working title)

Genre: narrative nonfiction / technical memoir-guide, written in real time as you learn. Each chapter follows the same four-beat structure so readers (and you) always know what's coming.

## The Four-Beat Chapter Template

1. **The Story** — a real-life scenario (yours, a client's, or a documented industry incident) that shows why this week's topic matters before any code appears.
2. **The Concept** — the theory explained in plain language, only as much as needed to build the thing.
3. **The Build** — the hands-on exercise or project step, with code, done live as you learn it.
4. **The Debrief** — what broke, what you'd do differently, and how this connects to a real job requirement (tie back to a job posting or salary band).
