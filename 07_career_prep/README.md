# 07_career_prep

Job search tracking and skill gap analysis for the job hunt.

- `SKILL_GAP_MATRIX.md`: required-in-market vs. current skill level, grounded in real job postings (public).
- `JOB_SEARCH_TRACKER.template.csv`: the tracker's column schema (public).
- `JOB_SEARCH_TRACKER.csv`: the real, filled-in tracker with actual companies/statuses. Gitignored, local-only. Real applications shouldn't be visible in a public repo while actively interviewing.
