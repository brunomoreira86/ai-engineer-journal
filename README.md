# The AI Engineer's Journal: Book + Project Repo

This repo is both the book manuscript and the project built while writing it. Every chapter is written only after the thing it teaches has actually been built and tested, so the book and the code stay honest to each other.

- `ROADMAP.md`: the 9-10 month learning plan, phase by phase.
- `BOOK_OUTLINE.md`: full book structure (23 chapters + 3 milestone project logs).
- `PROJECT_BOARD.csv`: IT-project-style backlog, one row per chapter/deliverable.
- `01_manuscript/`: the book chapters, organized by part.
- `02_exercises/` and `03_projects/`: the hands-on code that backs each chapter.
- `planning_journal/`: a running log of how this project itself is planned and managed, separate from the book content.
- `07_career_prep/`: job market research and skill gap tracking against real postings.

See `CLAUDE.md` for the full repo map and how this project is meant to be worked on.
