# 04_data_assets

Datasets used across exercises and the flagship projects (e.g. AskDila docs for the RAG chatbot, sample business docs, eval sets). Keep large/binary data out of git where possible — note the source and how to regenerate/download instead of committing it raw.

**Open source policy:** the portfolio projects (`03_projects/`) are meant to be public repos — code is public, but real AskDila business data/docs must NOT be committed. Use synthetic or sanitized sample data in the public repo and keep any real AskDila content local/`.gitignore`d.
