# Planning Journal

A running, dated log of how this project itself is planned and managed — separate from the AI engineering content in `ai-engineer-book/`.

This is not the roadmap and not the book manuscript. It's the record of *how we planned*: decisions made, why, what got reconsidered, what process/methodology we tried and whether it worked. Treat it as raw material — if it becomes its own book on planning/PM later, this is the source.

## Format

One file per entry, named `YYYY-MM-DD-short-slug.md`, newest decisions easiest to find via filename sort. Each entry:

```markdown
# YYYY-MM-DD — Title

**Context:** what prompted this
**Decision:** what we chose
**Why:** the reasoning
**Reconsider if:** signal that would make us revisit this
```

Keep entries short. This is a log, not an essay — write it in the moment, not polished after the fact.
